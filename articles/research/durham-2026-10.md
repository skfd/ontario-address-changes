# Research notes — Regional Municipality of Durham, 2026-10

Raw findings behind `articles/researched/durham-2026-10.md`. Notes, not prose.
Window researched: net 2026-09-15 → 2026-10-23; one changed snapshot in the month
(10-23); 30 pull days, 0 failed. Research done 2026-11-04.

Conventions: **FACT** = the linked page says it (fetched directly). **INFERENCE** = a
reading, not the source's. **EMPTY** = searched, nothing found. **SNIPPET** = seen only in
a search result; the page itself would not load, so not for print.

Source caveat: identity is MXADDRESSCODE, so a removal here means an asset id left the
layer, not necessarily that an address did. POSTAL_CODE is in `ignore_fields`. Durham sets
no `location_min_move_m`, so the floor is 0 (off): every move counts, however small.
Coordinates in the store carry five decimals (about 1 m), so distances below are good to
about a metre.

Flag queue: `python run.py flags` on 2026-11-04 shows 12 open flags (guelph, simcoe,
mississauga, york), none for durham. Brief has no HELD section.
