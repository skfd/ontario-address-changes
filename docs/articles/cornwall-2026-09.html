Thirty-three addresses land on one block at Tenth and Marlborough, and Mauricy Street gets a new postal code

On 11 September 2026 the City of Cornwall's address file gained 501 Tenth Street East and sixteen units inside it, eleven numbered units at 950 Marlborough Street, four at 933 Marlborough and a new 489 Pacific Avenue. That is 33 new addresses within about 150 metres of each other, in one update. Five days later, every address on Mauricy Street that had carried the postal code K6K 0B7 was rewritten to a different one.

Forty-eight more addresses in a file of about twenty thousand is a quarter of one per cent. Nearly all of it arrived on two days, 11 and 12 September.

Sixteen units at 501 Tenth Street East

501 Tenth Street East was not on the file before September. It arrived on 11 September with Units 1 to 16, and the file records a floor for each: four units on each of four levels, from floor −1 to floor 3. The record numbers the City gave them run unbroken, which is what points issued together look like.

Twenty-two metres away, 933 Marlborough Street, on file since the tracker started, gained Units 1, 2, 3 and D the same day. There is no A, B or C. Around the corner, 950 Marlborough Street gained Units 1 to 11, their points laid out in an even line about 64 metres long, and the original 950 point was moved 27 metres. 489 Pacific Avenue, 42 metres from 930 Marlborough, appeared alongside them.

What is on this block is not something the file can say, and the public record is silent too: searches for each of these addresses found no development application, listing or news item. A few streets east, 600 Tenth Street East gained Units A to D the same day.

Two more buildings get units

On 12 September 215 Saunders Drive, in the west end near Second Street West, gained Units 1 to 7, all of them recorded on the ground floor. On 25 September 105 Emma Avenue, near Pitt Street, gained Units A, B and C. Both original addresses are still on the file. Nothing public turned up for either.

Mauricy Street's postal code

On 16 September the file rewrote the postal code on all 24 Mauricy Street addresses that carried K6K 0B7. Twenty-three now read K6K 0A1; one, 3190, reads K6K 0C2. Nothing about the addresses themselves changed. Real-estate listings for new bungalows on the street already give K6K 0A1, for example 3149 Mauricy Street, so the file appears to have caught up with what was already in use. A listing for 3190 also says K6K 0A1, which the file does not; neither says which is right.

The same day brought a curiosity. A new point appeared labelled 3166 Mauricy Street, thirteen metres from the 3166 that was already there, with 3170 in its number field and a record number of zero. On 25 September it was reissued with a proper record number, still labelled 3166, still numbered 3170. The file has two 3166 Mauricy Streets and no 3170, and it does not say which label is the mistake.

What left

The month's two retirements are small. 3181 Mauricy Street came off and went straight back on with a new City record number, so it is in both counts. 409 Montreal Road left on 11 September, the same day the point for 407 next door was moved four metres; the file does not say whether the two were merged. At the other end of the road, 2801 Montreal Road arrived the day before; nothing public says what it is.

How this is measured — The tracker reads the City of Cornwall's published address layer daily and keeps a snapshot whenever the contents differ. September 2026 produced seven snapshots, from 9 to 25 September; the month's figures are one comparison between the last snapshot before the month (22 August) and the last one in it (25 September), so changes after the 25th belong to October. Gross activity was 51 additions and 3 removals; the extra one is the second 3166 Mauricy point, added and reissued inside the month. Thirty daily reads, none failed.
